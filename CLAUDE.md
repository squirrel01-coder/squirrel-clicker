# Правила для Claude

## Установка скиллов
Когда пользователь просит «скачай/поставь скилл X»:
1. Добавь строку в `.claude/setup-skills.sh` (`skill …` для отдельного скилла, `plugin …` для плагина из маркетплейса) — это облако.
   Для отдельного скилла добавь такую же строку `call :skill <имя> <git-url>` в `windows/setup-claude-on-D.bat` — это локальный компьютер пользователя (Windows, всё лежит в D:\Claude); пользователь перезапускает этот файл.
2. Запусти `bash .claude/setup-skills.sh`, чтобы скилл заработал в текущей сессии.
3. Закоммить и запушь в основную ветку репозитория. Setup script окружения скачивает этот файл с GitHub при старте каждой сессии, так что больше ничего делать не нужно.

Не копируй в репозиторий скиллы с лицензией, запрещающей распространение (например, docx/pdf/pptx/xlsx от Anthropic) — подключай их через `plugin`.
