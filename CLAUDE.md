# Правила для Claude

## Установка скиллов
Когда пользователь просит «скачай/поставь скилл X»:
1. Добавь строку в `.claude/setup-skills.sh` (`skill …` для отдельного скилла, `plugin …` для плагина из маркетплейса).
2. Запусти `bash .claude/setup-skills.sh`, чтобы скилл заработал в текущей сессии.
3. Закоммить и запушь.
4. Напомни пользователю обновить Setup script облачного окружения содержимым этого файла — только так скилл будет во всех сессиях.

Не копируй в репозиторий скиллы с лицензией, запрещающей распространение (например, docx/pdf/pptx/xlsx от Anthropic) — подключай их через `plugin`.
