# Озвучка через Azure Speech (бесплатно)

Ключ не хранится в файлах: облачная среда сама подставляет заголовок `Ocp-Apim-Subscription-Key`
в запросы к `swedencentral.tts.speech.microsoft.com` (секрет «Azure Speech» в настройках среды).
Поэтому скрипт ключ не передаёт и в коде его быть не должно. Никогда не проси пользователя прислать ключ в чат.

## Быстрый старт

```bash
S=~/.claude/skills/azure-tts/scripts/tts.py
python3 $S "Текст для озвучки" -o voice.mp3                       # один файл
python3 $S --lines script.txt --outdir vo/                         # по строке на фразу + vo/timeline.json
python3 $S --list ru-RU                                            # список голосов
```

Опции: `--voice` (по умолчанию `ru-RU-DmitryNeural`), `--rate` (`+8%` бодрее, `-5%` спокойнее),
`--pitch` (`+2%`), `--style` (если голос поддерживает), `--region` (по умолчанию `swedencentral`
или переменная `AZURE_SPEECH_REGION`).

## Голоса

- Русский: `ru-RU-DmitryNeural` (мужской, уверенный — для рекламы), `ru-RU-SvetlanaNeural`,
  `ru-RU-DariyaNeural` (женские). Полный список — `--list ru-RU`.
- Узбекский: `uz-UZ-SardorNeural` (м), `uz-UZ-MadinaNeural` (ж).
- Английский: `en-US-AndrewMultilingualNeural`, `en-US-AvaMultilingualNeural` и др.

## Как писать текст для озвучки

- Латиницу и аббревиатуры пиши так, как надо произнести: «Некстин», «си-ар-эм», «вотсап».
- Короткие фразы, по одной мысли. Для ролика — по строке на сцену (`--lines`), тогда в
  `timeline.json` будут длительности каждой фразы для синхронизации видео.
- Паузу внутри фразы можно задать SSML-тегом `<break time="300ms"/>` (передаётся как есть).

## Если не работает

- `HTTP 401` — в среде нет секрета «Azure Speech» или ключ неверный. Пользователь добавляет его в
  «Изменить облачную среду» → «Добавить секрет»: сайты `swedencentral.tts.speech.microsoft.com`,
  заголовок `Ocp-Apim-Subscription-Key`, без префикса, значение — КЛЮЧ 1 из Azure. Секрет
  подхватывается только новыми сессиями.
- `HTTP 429` — превышен лимит запросов F0 (20 в минуту): скрипт сам делает паузу и повторяет.
- Лимит 500 000 символов в месяц; один ролик ≈ 500 символов.
